# MiniFlow Studio V1 editor design

The visual editor extends the local dashboard. Its workbench has a searchable block palette, a node canvas, and a settings inspector. It uses the dashboard colors and MiniFlow mark. The implementation stays vanilla JavaScript, SVG, and CSS with no CDN.

[Superdesign editor draft](https://superdesign.dev/teams/142a11ca-be92-4fc1-b24f-2f6c76bb26f5/projects/7a602f7e-34d2-4ecb-bbf9-392177edc4b9?node=draft-variant-8e6b8243-9071-4414-979f-60ec3b686a1b) is the visual reference. Its generated HTML is a mockup; the shipping editor uses this repository's assets and APIs.
