What to watch for: 

        

          How to read this page
          
    
            
  • Graph: every box is one step of the job; an arrow means "this step needs the result of that one". Steps with no arrow between them can run at the same time.
    • 
            
  • Colours show each step's state: grey waiting, yellow ready, blue running (it pulses), orange retrying after a failure, green done, red failed, light grey skipped because something before it failed.
    • 
            
  • Shapes show the kind of worker: plain box = io (waits on the network or disk, runs on threads), stacked box = cpu (heavy calculation, runs on separate CPU cores), pill = async (many small waits juggled by one event loop). A dashed outline marks an optional step the job can finish without.
    • 
            
  • Timeline: one row per worker, one bar per attempt. Bars stacked above each other ran at the same time. Dotted orange curves are the pause before a retry.
    • 
            
  • Click any step to see what it does, what it produced and every attempt it made.
    •
