# MiniFlow design system

MiniFlow uses the existing neutral desktop workbench design. Light: background/panel #ffffff, sidebar #f7f7f8, text/accent #18181b, muted #71717a, borders #e7e7ea. Dark: background/panel #111113, sidebar #0b0b0d, raised panel #19191c, text/accent #ececef, muted #8b8b94, borders #222226. System/Inter sans, system/JetBrains Mono for code. 13px base, compact 12-15px headings, 8px radii. Buttons are neutral outlined; primary buttons invert text/background. Colour is reserved for task states. Existing themes also include Brutalist, Glass, Terminal. Body has 232px navigation sidebar; editor has palette, graph and settings. Mobile breakpoint 640/760px, intermediate editor reflow 1000px.

New Claude integration: prominent Ask Claude and Connect Claude controls in the Editor toolbar. A compact right-hand assistant pane with clear close action, selected-flow context, conversation, plain-language tool activity, multiline message box and Send/Stop. Connection setup is a native modal dialog with inside-MiniFlow sign-in status and external Claude Code/Claude Desktop setup instructions. Preserve the existing editor and all themes. At 375px use a full-width assistant sheet. Reuse the actual MiniFlow logo. Do not introduce new typography, gradients, accent colours, fictional account plans or unsupported sign-in claims.
